# Security Policy

## Supported Versions

We provide security updates for the current major release of Neurochrome Vault.

| Version | Supported          |
| ------- | ------------------ |
| 0.x / 1.x | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Neurochrome Vault and your local data seriously. If you discover a security vulnerability, please do not report it via public GitHub issues.

Instead, please report vulnerabilities privately via our Gumroad support contact or direct email. We will review all reports and issue OTA patches promptly.
